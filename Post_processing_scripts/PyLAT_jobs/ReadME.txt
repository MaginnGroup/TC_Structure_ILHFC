
To run PyLAT, you need to obtain a copy of the relevant software and scripts
You can obtain PyLAT from https://github.com/MaginnGroup/PyLAT

I created a separate conda env. with Python version 3.10 along with appropriate/corresponding versions of other relevant packages.

Using the latest Python version with the current (2022) version of PyLAT, may lead to certain incompatibility issues.

PyLAT requires specific formatting of file inputs for computing the requested properties. 

See the PyLAT documentation and readme.

The examples here may be useful.
