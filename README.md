# Nanostructural Origins of Anomalous Thermal Conductivity in Ionic Liquid-Hydrofluorocarbon Mixtures

This repository accompanies the research paper

**"Nanostructural Origins of Anomalous Thermal Conductivity in Ionic Liquid-Hydrofluorocarbon Mixtures"**

---

## Repository Contents

This repository contains LAMMPS input scripts, post-processing scripts, Jupyter notebooks, and data sheet for the final plots shown in the paper.
Below is a breakdown of the key folders and files:

### 1. LAMMPS Data Files
- `Data_Files` folder contains LAMMPS data files used for the NPT simulations for all systems.

### 2. LAMMPS Input Scripts
- `Example_LAMMPS_Input_Scripts` folder containing all LAMMPS input scripts for NPT simulations, box elongation, and heat flux decomposition simulations.

### 3. Jupyter notebooks and data sheet
- Located in the `Jupyter_Notebooks_and_DataSheet_Final_Plots` folder.

### 4. Postprocessing Scripts
- Located in the `Post_processing_scripts` folder. Contains `Extracting_and_Computing_Density_Lambda_HFD`, `Ion_clustering_analysis`, and  `PyLAT_jobs` subfolders. 


### 5. Output data and result files 
- `RDF_CN_Res_all`,  `TC_corr_HFD_final_outputs`, `Collated_Xray_Sq_all`, and `Collated_Clust_df_all` folders contain data and result files for RDFs, CNs, heat flux decomposition output files, collated MD X-ray S(q) outputs, and collated clustering analysis outputs.
